# 群控周期任务

统一聊天支持一次、每天、每周指定一天和每月指定一日的计划。计划预览显示设备、当地时间和时区，创建时固定设备成员；手机离线、忙碌或错过时间的当次记录为未执行，不自动补跑。取消后不再创建后续轮次。

每月 29、30 或 31 日遇到没有该日期的月份时跳过该月，预览中会显示此规则。每周多天、工作日、每隔一段时间和月底等规则暂不支持，不能当作已经设置成功。夏令时造成当地时间不存在或重复时，计划暂停并提示处理。

这些规则已有隔离环境的模拟回归；模型对自然语言的真实识别、正式服务器运行和手机定时执行仍需现场验证。生产部署前应先部署支持该计划格式的服务端，再发布对应网页，避免旧服务端接收新格式。

统一任务页会单独列出本计划仍在执行或等待处理的手机任务，即使较新的轮次因设备忙碌而未执行；用户可以打开原任务处理普通追问。系统授权、身份验证等仍须在手机处理。停止请求在手机确认终态前显示待确认；最近一次手机反馈时间只是快照，不代表实时在线。设备权限撤销后不展示对应任务信息。
