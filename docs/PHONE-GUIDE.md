# 手机安装单页说明

入口：`https://dongfengqi.top/bk-phone-guide.html`。源码与可离线打开的交付文件为 `vue/public/bk-phone-guide.html`；无 CDN、外部字体、分析脚本或后台提交，品牌 PNG 直接内嵌。设备勾选仅保存在访问者浏览器，不能代表服务器真实状态。

设计计划：白色 #ffffff、纸灰 #f4f7f6、墨绿 #123e30、品牌绿 #007d4b、正文 #243631、提示棕 #875214。使用系统中文无衬线字体，正文 17 px，标题 36 px；桌面左侧操作目录，右侧逐步说明，手机改为顶部短目录。步骤数字对应实际操作次序，区分管理员与手机现场操作者；不使用虚构应用截图。先以下载和接入动作组织内容，再写故障与管理员附录，避免相同卡片堆满页面。

核对依据（2026-11-10）：

- FIRERPA 官方 quick-start、install-server、properties、server-certificate、distributed-deployment；Shizuku 官方中文安装手册；Termux 官方下载说明。
- 本仓库 `AddDeviceDialog.vue`、`DevicesPage.vue`、中文语言包以及设备创建服务确认：添加设备 → 转发 → 备注 → 确认添加 → 每设备 `[pigeon]` 配置。转发接入与 WebRTC 媒体直连不是同一个开关。
- 当前部署公开参数仍为 WEB_PORT=18000、FWD_PORT=17000、MQP_PORT=18883。主登录入口为域名 HTTPS；手机配置按后台实际生成内容，不把登录端口 19000 机械替换进接入配置。
- 官方文档提供的 FIRERPA APK 与 Shizuku 13.6.0 镜像下载链接 HEAD 均为 200，类型为 Android APK，大小分别 8,411,050 / 2,571,773 字节。原站文件可能更新，手机服务 10.9 是现有验证基线，不宣称 APK 下载地址永久固定版本。
- Termux 是可选排障通道。现有第一台脚本固定 15555 / 16502 及身份，不能用于十台并发复制；指南不提供复用密钥或暴露 ADB 端口的指令。
- 已有 vivo 发生过 APK 状态不准与启动残留进程问题。指南如实给出“确认实际远控 → 查日志 → 管理员定向处理”的分支，不声称所有新机均可一键启动 / 重启自动恢复。

部署只增加这一份静态指南及小型发布记录；不替换应用 JS、不更改 Nginx 路由、不重启服务。后续正常前端构建会自动携带 public 文件。原应用里程碑 Tag 保持不变，本指南继续在 dev 提交。

验证：浏览器检查桌面 / 手机排版、锚点、逐设备清单隔离、存储不可用时提示、打印展开、反馈复制和离线资源；检查下载链接与指南 HTTPS 内容哈希。没有把文档检查称为第 2–10 台真机安装验收。
