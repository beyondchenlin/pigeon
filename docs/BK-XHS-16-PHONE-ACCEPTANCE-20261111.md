## 分批验收

1. 单机：真实连续 300000ms、到期重新核实会话身份和画面、截图自动上传、后台打开原图。布局不支持/离开会话/网络断开/人工接管必须未确认，不能以工具运行总时长冒充静默。
2. 接入剩余设备后按 4 → 8 → 16 台增加并发；每一批先只读验收，各手机仅一个活动任务。任何一台出现身份错配、证据串台、重复业务动作或后台看不到原图，停止扩大并发，保留失败现场。
3. 每台成功记录包含设备 ID、任务 ID、实际包哈希、原账号/目标的核验来源、`chat_quiet` evidence_id、`quiet_ms=300000`、`checked_at_ms`、`quiet_method=verified_profile_ui_and_pixels_v1`、图像大小与 SHA-256。不得把旧任务归档或 terminal/failure 图当成本次通过。
4. 服务器归档同一 evidence_id 仅一条，手机 ACK 后 pending 清空；完成后的证据补传不得提交新的业务任务。现有定向清单 503 / ACK 503 实测可复用为基线，但不冒称整机断网或真实收件人去重测试。
5. 逐批记录任务启动/导航/观察/归档耗时、失败原因、同步积压和实际服务器 CPU/内存/带宽。缺少真实测量时不承诺“2 核 2G 可接 50 台”；闲置连接数与同时执行、图像归档、模型服务限流分别记录。

## 当前边界与发布前事项

- r5 通用观察仅接受完整可见、不能滚动的原生会话列表；长列表、裁切、搜索框、草稿和身份不明仍失败关闭。图片和资料卡计入观察区域；动画或相对时间变化可能保守地重计时。
- 自主恢复在原任务期限内执行，最多 3 次 watch，重绑不清零。PIGEON 当前期限最大 600 秒；较晚发生的故障恢复后可能不足以重新观察 5 分钟，应明确未完成。独立后台复查调度及更长期恢复仍需单独实现父子任务归属，不能偷偷续跑发送或发布。
- 模型 Agent 在手机执行，推理依赖配置的模型服务；不将其描述成已部署手机离线大模型。
- 服务端不可变证据元数据与诊断原因补丁已上线：SSH 已恢复，原容器 46 项检查通过且无跳过，三个模块哈希及 API 服务启动、旧任务/证据留存均已核验。部署后新单机静默任务也已通过，连续观察 324353ms，截图回传与后台大图、ACK 清空均核实；详见 `BK-SERVER-PATCH-AND-SCROLL-20261111.md`。
- 当前证据为服务器私有本地盘，默认 2 GiB；云对象存储和多服务器共享归档尚未接入。视频素材云下载与截图归档存储分开验收。
