# 手机远控页视觉调整

根据用户确认的效果图继续在 `dev` 开发，主入口仍为 `/d/<device-id>/`。保持 BK 导航和白 / 浅灰 / 橙色视觉风格；不调整 `main`，不改变接入协议、后台权限或数据采集方式。

## 页面规格

- 桌面端以视口为工作区：手机画面完整显示，右侧属性独立滚动；小屏改为上下排列，保留全部操作。
- 标题优先显示品牌及型号，备注和设备 ID 放在第二行。
- 左上角明确固定 Logo 32px、品牌名 14px / 20px 行高、说明 10px / 15px 行高；Logo 与两行文字整体垂直居中，文字左边界一致。登录页的大号品牌仍使用独立变体。
- 保留属性、性能、文件、连接日志四个页签。属性按六组展示，开机时间、IP、心跳等低频字段折叠至“更多技术信息”。
- 电量、锁屏、亮屏状态置顶，系统数据和状态通道分别标记采集时间。缺失值不补成 100% 或 0%；断连 / 过期读数有提示，过期进度条改用琥珀色。
- 手机导航增加文字标签。画面按实际宽高等比适配容器，支持浏览器全屏、退出全屏和 Esc；改变容器尺寸不会重建正常视频连接。
- 帧率来自浏览器实际绘制帧数；暂未测量端到端延迟，保持“—”，不以 FPS 或网络请求时间替代。

## 发布和验证

复用既有依赖，运行 `vue-tsc --noEmit`、Vite 构建和真实浏览器验收。通过既有 `ops/deploy_frontend.py` 发布完整 `dev` 提交对应的静态文件，保留前一发布作为回滚；只平滑重载 Nginx，不重启手机服务。

验收覆盖指定的原 URL、品牌尺寸与对齐、桌面与窄屏、属性独立滚动、画面暂停 / 恢复、全屏、真实手机导航及属性读数。截图和详细结果保存在任务证据目录，不提交构建输出或截图到 Git。
