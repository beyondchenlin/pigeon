## 使用方式

1. 设备页提供“多卡片 / 列表 / 单卡片”。多卡片在手机竖屏按两列两行显示首屏四台；单卡片可切上一台、下一台，范围为当前分页。分组、状态、搜索、分页和每设备选择继续可用。
2. 点击在线设备画面进入远控。首次点画面只隐藏工具，不下发点击；随后触控正常传给手机。右边的“工具”恢复导航、手机切换与其他工具。
3. 回复前先在远程 App 点选输入框，再打开“文字输入”。支持中文、本机输入法和换行，点击“写入手机”粘贴。**不自动发送消息**，用户在 App 内核对后发送。
4. 草稿只保存在本页运行期间的内存，按设备隔离；刷新后不保留。写入失败保留草稿，不自动重发。输入提交期间不允许切换目标或穿透触控。
5. 手机后台底部为设备、总览、作业、更多；更多包含脚本、模型、用户、主题与账户功能。远控页面使用沉浸布局，后台导航不占传屏区域。
