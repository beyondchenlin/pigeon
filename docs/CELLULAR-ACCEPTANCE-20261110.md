# 单手机纯移动网络验收记录

范围：vivo V2220A / Android 14 / FIRERPA 10.9，Android shell UID 2000。只修改 dev，main 与界面不变。未 Root。

## 恢复连接时查明的问题

- 旧服务 PID 18561 已执行正常停止，但任务调度器等待未退出。四个直接子进程仅有 futex 等待线程；核对 UID、可执行文件、启动 ticks、父进程后清理这四个卡住的子进程，主进程自行退出，不需要杀主进程。这是本次停机卡住的直接证据，不等于证明所有历史媒体阻塞均有同一根因。
- 原先 BK FRP 安装器替换了原生 `bin/xfrpc`。运行中的子进程切换测试通过，但下一次原生启动报 `file broken`。按安装清单校验并恢复原始 ELF 后，启动成功。已撤回此安装方式：安装器在任何设备写入前拒绝新安装，保留回退功能。此前 BK 客户端的短重试数据只能作为历史试验，不能再声称当前运行版本具有同样重连时间。
- 不能将主服务进程的整个环境复制给新启动器。`__DNTNEEDRESPAWN__` 等内部标记会跳过原生解释器重新执行，导致用户扩展路径丢失。`ops/bk_service_lifecycle.py` 仅保留 Android 系统环境与指定的运行/用户目录，不复制内部标记或凭据。
- 新媒体扩展错误地把原生编码命令当作绝对 argv。实机原生命令的可执行名称为 `screen`，位于运行目录内 `lib/python3.12/site-packages/lamda/tool`，不能只在 bin 下查找。现按受信任的工具目录解析，仍使用 Bionic posix_spawn 避免 Python 多线程 fork 回调；不接受 shell 字符串。若遇到不支持的格式，保留原生媒体回退。
- Tornado WebSocket 升级后 HTTP stream 已分离；触控桥接通过该 stream 取端口会失败。改为读取原生服务环境中的监听端口，仍固定连接本机回环地址并传递原有认证令牌。
- FIRERPA 的 HTTP 扩展通过 executor 调用处理函数，不接受 coroutine。健康接口已改为同步函数。

## 初步网络切换记录

北京时间 20:27:06 请求关闭 Wi-Fi，移动数据原已开启。手机在 Wi-Fi=0 时报告 `NR_SA`，云端认证 RPC 可响应，证明本机 SIM 的纯 5G 通路可用。

原生 FRP 0.71.0 在 20:27:36 关闭旧出口连接，20:27:59 在移动出口重新登录。新建代理后 RPC 恢复。锁屏期间手机定时任务明显晚于预定时间执行，因此不能用这一轮定时计划代替精确的断网时长。此轮已自动恢复 Wi-Fi。

用户随后主动移除锁屏密码。系统确认 `showing=false`、`secure=false`、`mInputRestricted=false`。这不等于重启后 Shizuku 会自动恢复授权。

## 15 分钟实机结果

北京时间 2026-11-10 20:57:49–21:12:49，关闭 Wi-Fi 900.5 秒。手机每 15 秒记录网络状态，样本均为 `wifi_on=0`、`mobile_data=1`、`NR_SA`（两次人为关闭数据的 15 秒区间另有独立记录）。未使用 WireGuard、电脑 USB 或 Root。

## 延迟结论与未通过部分

不能标记为长期稳定、低延迟验收通过。短时连接与两次自动重连通过，但一次恢复仍接近 48 秒，尚未验证整夜待机、手机重启、其他运营商或 10 台设备。

本轮先发现验收浏览器 requestAnimationFrame 约每 1017 ms 才执行一次，导致点击到画面统计失真。这一阶段的 12 次约 1 秒结果不能作为产品真实延迟。用户将窗口恢复前台后，绘制间隔恢复约 7 ms，但后续实际点击仍仅取得 4 个 2.30–2.65 秒的变色样本，第 5 次超过 3.5 秒；不能用这些小样本宣称延迟达标。随后画面确认点击与滑动最终均执行并释放。

同期直连 RTT 约 40–45 ms、未观察到 RTP 丢包；4 次点击采样窗口内平均解码耗时约 0.48 ms/帧、平均抖动缓冲约 16.2 ms/帧，扩展媒体队列观测深度/丢弃均为 0。这些证据不足以唯一归因，但不支持将数秒延迟简单归咎于香港服务器距离。下一步应关联触控实际注入时间、手机屏幕变化、编码包产生/发送及浏览器呈现时间，优先定位手机采集与媒体发送间歇；同时改进原生转发器的合法配置/启动集成，不能再次替换受完整性检查保护的 xfrpc 文件。

Python 相关测试合计 35 项通过；界面、前端构建及 main 均未修改。本次只提交恢复兼容性修复与实测记录到 dev，不打“长期稳定”里程碑 Tag。
