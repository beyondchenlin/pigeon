## 恢复语义

- 服务端收据在首次派发之前持久化；连接未知时只按原 task_id 查询，不重新创建。
- 短暂断线保留上次收到的进度；旧快照不是实时证明。
- 到期取消意图持久化，恢复连接后按原编号取消并核实终态；accepted 不等于 cancelled。
- 手机进程中断后的 failed/interrupted 是失败终态，不能自动宣称续跑。
- 同一个外部发布/消息是否完成不能只由 request_id 去重证明，需业务结果对账。
